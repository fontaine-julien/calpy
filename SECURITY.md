# Politique de sécurité

Les correctifs de sécurité sont intégrés à la version courante de CalPy.

Pour signaler une vulnérabilité, ouvrez l’onglet **Security** du dépôt GitHub, puis **Advisories** et **Report a vulnerability**. Le signalement est transmis en privé.

Indiquez la version ou le commit utilisé, votre système d’exploitation, les étapes pour reproduire le problème et son impact possible. Utilisez des exemples fictifs et retirez toute donnée personnelle des captures et fichiers joints.

# Security policy

Security fixes are made to the current version of CalPy.

To report a vulnerability privately, open the GitHub repository’s **Security** tab, select **Advisories**, then **Report a vulnerability**.

Include the version or commit, your operating system, the steps to reproduce the issue, and its potential impact. Use fictional examples and remove personal data from screenshots and attachments.
